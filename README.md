# E-commerce Customer Retention & Purchase Prediction

## Overview
A machine learning project focused on analyzing e-commerce customer behavior and predicting customer retention and purchase outcomes.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Data Visualization

## Project Files
- main.py: Main project workflow
- inspect_data.py: Dataset inspection and exploratory analysis

## Dataset
The raw datasets are excluded from this repository. Place the required CSV files inside the data/ directory before running the project.

## Status
Model implementation stage.
